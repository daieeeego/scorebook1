# 少年野球スコアブック 試作版

入力UIの検証が目的の試作です。印刷・集計・同期は入っていません。

## 動かす（Windows）

Node.js 18以上が必要です。

```
npm install
npm run dev
```

表示されたURLをブラウザで開きます。同じWi-Fi内のスマホから見る場合は `npm run dev -- --host` で起動し、表示される Network のURLを開いてください。

## 配る

```
npm run build
```

`dist` フォルダができます。これをそのまま公開すれば動きます。一番手軽なのは Netlify Drop で、ブラウザに `dist` フォルダをドラッグするだけでURLが発行されます。GitHub Pages、Cloudflare Pages、Vercel でも動きます。

発行されたURLをLINEで共有し、スマホで開いて「ホーム画面に追加」してもらうとアプリのように起動します。オフラインでも動きます。

## 試してもらうときのお願い

1. ホーム画面に追加してから使う
2. 実際の試合、または試合の動画を見ながら入力する
3. 画面上部の「タップ数 / プレー」の数字を最後に控える
4. 手が止まった場面、意味が分からなかったボタンを覚えておく

数字より、**どこで詰まったか**のほうが重要です。

## 入っているもの

- 1球ごとの投球記録（ボール／ストライク／ファウル）
- 打球方向と打席結果の記録
- 走者の自動進塁と、判断が分かれる場面の質問
- 盗塁・暴投・捕逸などの走者プレー
- 「あとで決める」による保留とメモ
- 1選択ずつ戻せる取り消し
- 投球数の常時表示
- 自動保存（閉じても続きから再開）
- JSON書き出し

## 入っていないもの

- 選手交代、代打・代走
- 印刷、PDF出力
- 成績集計、分析
- 端末間の同期
- 選手氏名（背番号のみ。個人情報を端末に残さないため）

## データについて

記録はブラウザの localStorage に保存されます。端末の中だけで、どこにも送信されません。試合が終わったら「書き出す」でJSONを保存してください。「新しい試合」を押すと前の試合は消えます。

## 構成

```
src/rules.js   ルールエンジン（UIから独立した純粋関数）
src/App.jsx    画面
```

盤面の状態は保存せず、イベント列を畳み込んで導出しています。ルールを直したら過去のイベント列を再生するだけで結果が再計算されます。
