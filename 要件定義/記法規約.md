## 1. 1打席セルの構成

セルは横に3つの領域を持つ。

```
┌─────┬───────────────┬──────────┐
│ ボール  │               │  ← 右上：関連走者の打順 (n)、得点 ⃝n │
│ カウント │   ダイヤモンド図    │            │
│  欄   │  中央：アウトカウント／得点 │  ← 右下：打者結果の記号   │
│ （縦に  │  辺：走塁の経路      │            │
│  積む） │               │            │
└─────┴───────────────┴──────────┘
```

| 領域 | 書くもの |
|---|---|
| 左の細い帯 | 1球ごとの投球結果を上から順に縦に積む（§2） |
| ダイヤモンド図の辺 | 走者が進んだ塁の経路をなぞる。進んだ塁の数だけ辺が埋まる |
| ダイヤモンド図の中央 | アウトカウント（I／II／III）、得点なら ● |
| セル右上 | 関連する打者の打順（(4) など）、その打者の時に得点なら ④ |
| セル右下 | 打者結果の記号（守備位置番号と補助記号） |
| セルの上部 | ピッチャー交代（§9） |
| セルの左側 | 攻撃の交代（PH・PR）（§9） |

## 2. ボールカウント欄

| 記号 | 意味 |
|---|---|
| ● | ボール |
| ○ | 見逃しストライク |
| × | 空振り |
| ― | ファール（後方バックネット側） |
| ⌐（右上から下へ折れる線） | ファール（一塁側） |
| L | ファール（三塁側） |
| ○ᵍ | バント構えで見逃し |
| ×ᵍ | バント空振り |
| Lᵍ | バントファール（三塁側） |

バントを表す添え字として、右肩に**小さなカタカナの「ギ」**を付す。**犠（犠打）の「ギ」**である。打者結果の欄では犠打・犠飛を `△` で表す（§4）が、投球欄では同じ「犠牲」の概念を `ギ` で表す。

**ストライクは「見逃し（○）」と「空振り（×）」を必ず書き分ける。** 三振の記号（K と SO）がこの区別に依存する。

**ファールは方向を3種に書き分ける。**

## 3. 守備番号

| 番号 | 守備位置 | 略号 |
|---|---|---|
| 1 | 投手（ピッチャー） | P |
| 2 | 捕手（キャッチャー） | C |
| 3 | 一塁手（ファースト） | 1B |
| 4 | 二塁手（セカンド） | 2B |
| 5 | 三塁手（サード） | 3B |
| 6 | 遊撃手（ショート） | SS |
| 7 | 左翼手（レフト） | LF |
| 8 | 中堅手（センター） | CF |
| 9 | 右翼手（ライト） | RF |

- 守備の関与順は番号を `-` で結ぶ（`1-6-3` = 投手→遊撃手→一塁手）。

### 塁の記号

守備番号のあとに塁の記号を付けると、**その野手が自分でその塁を踏んでアウトにした**（送球を伴わない自力処理）ことを表す。

| 記号 | 塁 |
|---|---|
| A | 一塁 |
| B | 二塁 |
| C | 三塁 |
| D | 本塁 |

`3A` = 一塁手が打球を捕り、そのまま一塁ベースを踏んでアウト（ファーストゴロの自力処理）。
`3-1` = 一塁手が捕球し、カバーに入った投手へ送球してアウト。両者は別のプレーである。

**`B` は前後で意味が違う。** 前に置く `B` はバント（`B 5-3` = バントヒット）、後ろに置く `B` は二塁を指す。位置で区別する。
- 守備位置の**間**に落ちた打球は番号を `.` で結ぶ（`7.8` = 左翼手と中堅手の間＝左中間）。
- `.` は打球の種類を表す文字と守備位置をつなぐのにも使う（`T.8` = センターへのテキサスヒット）。

## 4. 打球の性質を表す補助記号

**記法の基幹。** 守備番号に添える線で、打球の種類を書き分ける。

| 補助記号 | 意味 | 例 |
|---|---|---|
| 番号の**下**に凵（下向きのコの字） | ゴロ | `1-3`（凵付き）= ピッチャーゴロ |
| 番号の**上**に⌐（上向きのコの字） | フライ | `3F`（⌐付き）= ファーストファールフライ |
| 番号の**上**に横線（一） | ライナー | `4`（一付き）= セカンドライナー |
| △ を前置 | 犠牲（犠打・犠飛） | `△9` = ライト犠牲フライ |
| 一塁への経路を弦として、外へふくらむ**弧**を描く | **内野安打**（打者がセーフ） | `6-3` を弧で囲む = ショート内野安打 |

**弧は「ヒットの印」ではなく「内野安打の印」である。** `6-3` は本来ショートゴロ**アウト**の書き方であり、弧がなければアウトと読まれる。弧は打者がセーフだったことを示す。外野へのヒット（`7`）は一塁への経路だけで足りるため弧を描かない。

弧は独立した円ではなく、**ダイヤモンドの右下辺（＝打者走者が一塁へ進んだ経路）を弦として、その外側にふくらませて描く**。凡例では走塁経路が描かれていないため閉じた丸に見えるが、同じ記号である。

## 9. 選手交代

**選手交代時は、交代のタイミングでスコア表に波線を記入し、識別する。**

| 記号 | 意味 |
|---|---|
| PH | 代打（ピンチヒッター） |
| PR | 代走（ピンチランナー） |
| P | ピッチャー交代 |
| 臨時代走 | バッターが頭に死球を受け、その選手を一時的にベンチに下げ、代わりの（出場中）選手が代走すること。**その回の攻撃まで継続。** |

### 記入位置
- **ピッチャー交代**は該当欄の**上部**に、`P 選手名` の形で書く（記入例では `P ピガ子`）。
- **攻撃の交代（PH・PR）**は該当欄の**左側**に、`PH 選手名` の形で書く（記入例では `PH ピガ男`）。
- 波線は交代のタイミングを示すため、欄の境目に引く。

### 選手名欄
選手名の下欄に、変更・交代の内容を書く。

- 変更後のポジション
- 選手名（交代の場合）
- 変更・交代イニング（**表 = オ ／ 裏 = ウ**）

記入例（原本より）：

| 守備 | 名前 | 交代 |
|---|---|---|
| 6 | ピガ子 | - |
| 1 | 〃 | 4オ |
| | | |
| 1 | ピガ太郎 | - |
| 6 | ピガ男 | 4オ |

遊撃手だったピガ子が4回表に投手へ移り、投手だったピガ太郎に代わってピガ男が遊撃手に入った、という読み方になる。同一選手の継続は `〃` で表す。

## 10. 記入例

### ダブルプレー
- 走者のセル：右上 `(2)1-6`、右 `FO`、中央 `I`、下 `H`
- 打者のセル：`1-6-3`、中央 `II`、左 `DP`
- 2つのセルを大きな `}` で括り、**一つのプレーとしてまとめる**
- **最後の結果球は書かない**（DPを成立させた投球の記号を投球欄に残さない）

### フィルダースチョイス（FC）
- 走者のセル：`7.`（レフト前ヒット）、右上 `(4)`
- 打者のセル：`5-4FC`
- サードゴロをセカンドに投げるもセーフ、バッターもセーフとなり FC が記録される
- 4番バッターの時に進塁

### バント成功（△）
- 走者のセル：`6-3`（弧で囲む＝内野安打）、右上 `(6)`、二塁への進塁
- 打者のセル：`△1-3`、中央 `I`
- ピッチャー前送りバント成功、バッターはファーストでアウト

### バント失敗（アウト）
- 走者のセル：右上 `(6)1-6`、右 `FO`、中央 `I`
- 打者のセル：`1-6`
- 送りバントするもランナーアウト、バッターはファーストセーフ
- **※このとき △ は書かない**

### 長打で得点
- 走者のセル：`5E`（サードゴロエラーで出塁）、中央 `●`、右上 `⑤`、`↰`で本塁までの進塁
- 打者のセル：`7.8`（フライ記号）＋二塁までの経路＝左中間のツーベース
- 5番バッターのツーベースでファーストからホームへ得点

### ワンヒットワンエラー
- `4-3` を弧で囲む＝セカンドへの内野安打。**記録はヒット**
- そこから `↑` で二塁へ進塁し、上に `4ET-3`
- セカンドへの進塁は送球エラー（高投）によるもの。**記録はエラー**
- 1つの打席で「ヒット」と「エラー」が同時に記録される

### 書き起こし全体の信頼性について

上記のうち **A・C・D と弧の意味の4件は、いずれも指摘を受けて初めて誤りに気づいた**ものである。手書きの細部（濁点、線の向き、罫線との重なり）は写真からの判読を誤りやすい。

**「解決済み」と書いた箇所も含め、規約を作成した人に一度通して確認してもらうこと。** 特に判別が細かいのは次の箇所である。

- ファール3種（`―` 後方／`⌐` 一塁側／`L` 三塁側）。`⌐` と `L` は左右反転の関係にあり取り違えやすい
- エラーの悪送球（`6E`**`T`**`-3` 高投／`6E`**`⊥`**`-3` 低投）。T を 7 と読み違えた前例があるため、この T も要確認
- `Ϗ`（振り逃げ）が K の左右反転で合っているか
- `B'`（敬遠四球）のアポストロフィの有無

## 13. 現在の試作との差分

**この規約は、現在の試作が表現できる範囲を大きく超えている。**
印刷（FR-23）を実現するには、記録するイベントの粒度そのものを上げる必要がある。

### 13.1 投球結果の粒度が足りない

| | 現在の試作 | 規約が要求するもの |
|---|---|---|
| 種類 | ボール／ストライク／ファウル の3種 | ボール／見逃し／空振り／ファール3方向／バント3種 の9種 |

三振を `K`（見逃し）と `SO`（空振り）に書き分けるため、**最後の投球が見逃しか空振りかの記録が必須**。現在はどちらも「ストライク」で潰れている。

**タップ数（SC-04）への影響は小さい。** 「ストライク」1ボタンを「見逃し」「空振り」の2ボタンに割るだけなら、押す回数は変わらずボタンが増えるだけである。ファールの3方向も同様。§12.2（選択肢の位置を文脈で変えない）にも反しない。バント構えのみ、モード切替として1タップ増える。

### 13.2 守備の関与順（fielders）が必須

規約はほぼ全ての打球で `6-3`、`1-6-3`、`5-4FC` のような**関与順**を要求する。現在は打球方向を1箇所タップするだけで、関与順を持たない。

v0.3 §6.4 では `fielders` を Phase 2 としていたが、**この規約で印刷するなら Phase 1 相当の必須項目**である。入力は「守備位置を順にタップする」で表現でき、現在の1タップを1〜3タップに拡張する形になる。

### 13.3 表現できないイベント種別

現在の打席結果は13種。規約はおよそ40種を区別する。不足しているもの：

- **投球・打席**：死球 DB、敬遠 B'、振り逃げ Ϗ、3バント失敗 K³、インフィールドフライ FF、打撃妨害 IF
- **打球の性質**：ゴロ／フライ／ライナーの区別（現在は「ゴロアウト／フライアウト／ライナーアウト」はあるが、安打側に性質の区別がない）
- **犠打・犠飛**：△、スクイズ、送りバント、タッチアップ、バントヒット BH
- **エラーの種別**：ゴロエラー／フライエラー（落球）／悪送球（高投 T・低投 ⊥）
- **アウトの成立方法**：フォースアウト FO とタッチアウト TO の区別
- **走者**：ボーク BK、オブストラクション OB、イリーガルプレー IP、盗塁アウトの経路（`2-6TO`）
- **複合**：DP／TP を「一つのプレーとしてまとめる」構造。1打席で「ヒット＋エラー」が同時に立つケース（§10 ワンヒットワンエラー）

### 13.4 データモデルの変更が不要なもの

- **「何番バッターの時か」（`(4)` / `④`）** は、イベント列の順序から導出できる。追加入力は不要。
- **アウトカウント I／II／III、残塁 ℓ、得点 ●** も導出できる。「イニング終了時、空欄NG」は自動で満たせる。
- **選手交代の記入位置と内容**（ポジション・選手名・交代イニング）は、実装済みの交代モデルが持つ情報で足りる。印刷時の配置ルールとして使えばよい。ただし**臨時代走**（頭部死球による一時的な代走、その回限り）は概念として存在しない。

### 13.5 集計5項目

投球数は実装済み（FR-19）。安打数・四死球数・三振数・盗塁数は `deriveStats` に追加すれば導出できる。ただし**四死球数には死球（DB）の記録が要る**ため、13.3 の対応が前提になる。

## 14. 判断が必要な点

以下は仕様の選択であり、実装者では決められない。

| # | 論点 | 選択肢 |
|---|---|---|
| 1 | 投球の粒度をどこまで上げるか | (a) 見逃し／空振りのみ分ける（三振の書き分けに最低限必要）<br>(b) ファール方向も分ける<br>(c) バント構えまで対応する |
| 2 | 守備の関与順を Phase 1 に入れるか | 印刷を実現するなら必須。ただしタップ数が増える |
| 3 | 規約の全記号を網羅するか | (a) 全て実装する<br>(b) 学童で頻出のものに絞り、残りは「保留」で受けて試合後に確定する |
| 4 | DP／TP の「まとめ」構造 | 複数の打席セルにまたがる1プレーを、イベント列でどう表現するか |

**3(b) は現実的な逃げ道である。** v0.3 §12.6「記録を止めない」のとおり、頻度の低い事象（IP、OB、FF、BK）は保留で受けてしまい、試合後に確定させれば、入力の負荷を上げずに記法を満たせる。
